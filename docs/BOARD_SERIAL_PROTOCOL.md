# STM32 实板串口遥测协议 v1

板端 USART1/TX1 单向发送，115200 baud、8 数据位、无校验、1 停止位。上位机只读。每约 200 ms 发送一帧；每项测量保持自己的真实采样周期，`age_*` 表示距离最近一次**成功**采样的毫秒数。未成功采样的字段由 `valid_mask` 标为无效，上位机不显示旧值为实时值。

所有多字节整数均为小端序；一帧共 49 字节：

| 偏移 | 长度 | 内容 |
| ---: | ---: | --- |
| 0 | 2 | 同步字 `A5 5A` |
| 2 | 1 | 版本，固定 `1` |
| 3 | 1 | 类型，`1` 为状态快照 |
| 4 | 1 | 载荷长度，固定 `40` |
| 5 | 2 | 序号，`uint16` 回绕 |
| 7 | 4 | FreeRTOS 运行时间，`uint32` ms |
| 11 | 10 | 电芯 1–5，`uint16[5]` mV |
| 21 | 2 | 总压，`uint16` mV |
| 23 | 2 | 实测电流，`int16` mA；正值充电 |
| 25 | 2 | 电芯温度，`int16`，单位 0.1 °C |
| 27 | 2 | SOC，`uint16`，单位 0.1% |
| 29 | 1 | 模式：0 待机、1 充电、2 放电、3 休眠、255 未知 |
| 30 | 2 | 故障位图，定义见下文 |
| 32 | 1 | 均衡寄存器读回位图，bit 0 对应电芯 1 |
| 33 | 1 | `SYS_CTRL2` 读回：bit 0 CHG、bit 1 DSG |
| 34 | 1 | `valid_mask`，定义见下文 |
| 35 | 2 | 保留，发送端置零 |
| 37 | 10 | 电芯、总压、电流、温度、SOC 的采样年龄，`uint16[5]` ms；无效时 `65535` |
| 47 | 2 | CRC-16/CCITT-FALSE：初值 `FFFF`、多项式 `1021`，覆盖偏移 2–46 |

`valid_mask` 的 bit 0–6 分别表示电芯、总压、电流、温度、SOC、MOS 读回、均衡读回有效。BQ76920 采集或 CRC 读取失败时，对应 bit 清零；旧数值仅用于诊断，不用于实时显示。故障位沿用上位机统一定义：bit 0 过压、1 充电过流、2 充电过温、3 充电低温、4 欠压、5 放电过流、6 短路、7 放电过温、8 放电低温、9 采样无效。课程板端原保护状态一次只能存一个故障枚举，本协议忠实上报现有状态；不能据此推断未被记录的并发故障。

上位机按长度和 CRC 接收，并在坏帧后重新寻找同步字；序号不连续写入事件记录。超过 1 秒无有效帧显示“数据过期”。协议没有下行命令，原课程固件的文本日志不能按此协议解析。
